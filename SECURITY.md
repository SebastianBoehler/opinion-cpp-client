# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/SebastianBoehler/opinion-cpp-client/security/advisories/new) for this repository.

Please include the version (`opinion::version_string` or the git revision), the call path, and what an attacker can do. Give the maintainers time to fix the issue before discussing it in public.

Do not open a public issue for an unfixed vulnerability. Trading-loss questions, API behavior, and feature requests belong in [Issues](https://github.com/SebastianBoehler/opinion-cpp-client/issues).
